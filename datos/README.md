# Datos del proyecto

Toda la recolección vive acá, centralizada.

- **`propio/`** — clips grabados por el equipo con [captura-web](../captura-web/). Subcarpeta por palabra o por persona, como les resulte más fácil de ordenar; los nombres de archivo ya vienen numerados y etiquetados desde la herramienta de captura.
- **`externos/`** — cualquier dataset externo que terminen usando (ej. LSA64), sin procesar, tal como se descarga. Si el peso es un problema para el repo, esta carpeta puede quedar fuera de git y documentarse acá cómo volver a bajarla.

Nada de esto se sube a Vercel — `captura-web/` es lo único que se deploya ahí.
